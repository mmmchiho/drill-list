# 教材リスト

- `index.html` … スマホ用の教材リスト（GitHub Pagesで公開）
  - **一覧**：検索すると「持っています ✓／持っていません」が一目で分かります
  - **編集**：教材名・保管形態（紙のみ/PDFのみ/紙+PDF）・紙の保管場所・備考を編集（PDF＝Googleドライブに保存済み）
- `materials.csv` … 一覧のバックアップ。GitHubで開くとそのまま表として表示されます

## CSVの更新方法
1. 「編集」タブ → 「CSV書き出し」
2. ダウンロードされた `materials.csv` を、GitHubのリポジトリに同じ名前でアップロード（Add file → Upload files）
3. Commit changes
